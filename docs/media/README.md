# README media

The READMEs have commented-out slots for a demo GIF. Record the media, put it here, and uncomment the `<img>` line at the top of `README.md` and `README.zh-CN.md`.

| File | What to record | Specs |
|---|---|---|
| `demo.gif` | One full turn: the prompt comes in (task-accept, rolls up sleeves) → thinking → typing → red "Can I run npm test?" bubble with the plead → done-exhausted → finger heart | 5–8 s, 720 px wide, under 5 MB, loops cleanly. Use the right-click "simulate agent state" menu to stage it |
| `fling.gif` | Drag the pet, fling it at the top edge, it hangs, slips to one arm, drops, dizzy landing | 4–6 s, same specs |
| `characters.png` | All 8 characters side by side | 1280×640, also usable as the GitHub social preview (Settings → Social preview) |
| `demo.mp4` | 30 s version with a real Claude Code session next to the pet, for X / Reddit / Bilibili | 1080p, 16:9, plus a 9:16 crop for short-video platforms |

Keep each file small: everything here ships with every clone and plugin install.
